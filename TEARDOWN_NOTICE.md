# ⚠️ AVISO DE DESMANTELAMIENTO DE INFRAESTRUCTURA EN LA NUBE ⚠️

Fecha: 5 de Junio de 2026

Por solicitud del usuario, la infraestructura en la nube asociada a este proyecto ha sido **eliminada** para garantizar la seguridad y privacidad. 

### Elementos eliminados:
- Despliegues asociados en plataformas de hosting como **Vercel** y configuraciones de terceros.

El código fuente local se mantiene intacto. El repositorio de GitHub ha sido configurado como **PRIVADO**, y se ha creado un repositorio público tipo "Showcase" que solo contiene el `README.md` para que el público pueda leer sobre el proyecto sin acceder al código fuente.
